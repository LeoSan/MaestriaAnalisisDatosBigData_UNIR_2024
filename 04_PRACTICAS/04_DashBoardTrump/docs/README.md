# Analysis Portfolio: Trump vs Brent Oil (v3.0 Final)

Este proyecto es una herramienta de análisis de datos y visualización interactiva de alto impacto, diseñada para identificar la correlación entre la comunicación geopolítica y los precios globales de energía.

## 🚀 Logros del Proyecto
El proyecto ha completado su primera fase de desarrollo con éxito:

- **Unificación de Datos (Cruce de Lupa):** Se logró alinear cronológicamente el precio del barril de Brent con el histórico de tweets, permitiendo una visión de 360° día tras día.
- **Dashboad Interactivo:** Implementación de una interfaz fluida que muestra "No hay coincidencia" en periodos de silencio y detalla el impacto en periodos de ruido social.
- **Visualización de Alta Densidad:** Uso de D3.js para manejar series temporales extensas con animaciones de entrada y transiciones automáticas.
- **Arquitectura Escalable:** El proyecto está organizado en directorios profesionales (`src`, `data`, `docs`) permitiendo una fácil transición hacia una integración con APIs en vivo.

## 🎨 Características Técnicas
- **Eje de Tiempo Continuo:** El precio del Brent es la rama principal, actuando como referencia constante.
- **Filtros por Periodo:** Selector de años (2017-2021) para análisis de micro-tendencias.
- **Detalle Dinámico:** Tooltips inteligentes y Sidebar histórico que muestran el texto original y el precio del mercado sincronizado.
- **Estética Modern Design:** Glassmorphism UI, Dark Mode y tipografía curada (Outfit/Inter).

## 📊 Fuentes de Información
- **Mercado:** FRED (Federal Reserve Economic Data) - Serie DCOILBRENTEU.
- **Social:** Historical Archive (2017-2021) @realDonaldTrump.
